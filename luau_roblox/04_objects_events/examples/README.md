# Примеры к уроку 4

[Открыть урок «Объекты и события Roblox»](../04_objects_and_events.md)

## Запуск в Studio

1. Открой Baseplate, нажми Stop и отключи учебные Script прошлых уроков.
2. Создай один обычный **Script Lesson04 в ServerScriptService**. Для всех файлов здесь используется серверный Script, а не LocalScript или ModuleScript.
3. Открой выбранный файл на GitHub, скопируй его код целиком и замени содержимое Lesson04.
4. Открой Output, очисти сообщения и запусти Test с персонажем.
5. Для следующего примера сначала нажми Stop. Не запускай все файлы одновременно.

Файлы .server.luau в репозитории — обычные текстовые исходники. Они не создают объекты в Explorer без копирования кода или специальной синхронизации; плагины для прохождения урока не требуются. Сцену и код сохраняй после Stop.

## Особенности интерактивных примеров

В примере касания площадка находится около (0, 1, −12). Подойди и запрыгни на неё. Обработчик принимает детали с Humanoid у непосредственного родителя; это учебный фильтр частей персонажа, не проверка исключительно Player. Тест с двумя неподвижными наложенными Anchored-деталями не заменяет физический контакт персонажа.

В примере пульта подойди к Control около (0, 1, −10), чтобы оказаться ближе 10 studs. Взаимодействуй через подсказку E. После активации она примерно на секунду отключается. Проект имеет общее состояние для всего сервера.

Имя Lesson04Control защищено проверкой от случайной второй копии: если папка уже есть, новый запуск этого кода выводит предупреждение и не заменяет её. Для чистой проверки используй Stop и новый Test.

## Что проверено автоматически

- Все **6 файлов** проходят синтаксическую компиляцию официальным [Luau 0.745](https://github.com/luau-lang/luau/releases/tag/0.745).
- Их неизменённый код выполнен в ограниченной тестовой модели объектов и сигналов. Проверены **8 сценариев**: свойства; дерево и поиск; скрытие/возврат/уничтожение; фильтр касаний и повторный вход; отключение сигнала; цикл создания/удаления/повторного создания куба; защита от дублирования системы; диагноз неисправного Connect из домашнего задания.
- Проверено, что во время моделируемой паузы не создаётся второй куб, а после уничтожения исчезает и дочерний источник света.
- Проверены ссылки, файлы изображений, число кадров и длительность GIF. Схемы и ключевые кадры просмотрены визуально.

## Граница проверки

**Тестовая модель не является Roblox Engine.** Она проверяет ветвления, ссылки, состояние и вызовы ограниченного набора методов. Она не воспроизводит физику Touched, появление подсказки, сетевую репликацию или точный планировщик движка. Проверку подключения к отдельной временной сцене Studio выполнить не удалось: подключённый Studio возвращал `Place is not open`. В открытые пользовательские игры изменения для проверки не вносились.

Поэтому результат запуска именно в Studio проверяется по таблицам сценариев в основном уроке. API сверены с официальными описаниями [Instance](https://github.com/Roblox/creator-docs/blob/c8f5276703948ef4868c9b9fd44fae619dbe2f11/content/en-us/reference/engine/classes/Instance.yaml), [BasePart](https://github.com/Roblox/creator-docs/blob/c8f5276703948ef4868c9b9fd44fae619dbe2f11/content/en-us/reference/engine/classes/BasePart.yaml), [ProximityPrompt](https://github.com/Roblox/creator-docs/blob/c8f5276703948ef4868c9b9fd44fae619dbe2f11/content/en-us/reference/engine/classes/ProximityPrompt.yaml) и [событий](https://github.com/Roblox/creator-docs/blob/c8f5276703948ef4868c9b9fd44fae619dbe2f11/content/en-us/scripting/events/index.md).
