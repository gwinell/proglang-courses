# Запускаемые примеры к уроку 2

[К уроку «Основы Luau»](../02_luau_basics.md)

## Как запустить в Roblox Studio

1. Открой файл примера на GitHub. Используй Raw или кнопку копирования, чтобы получить сам код без оформления страницы.
2. После Stop открой учебный Script `Lesson02` в ServerScriptService.
3. Замени его содержимое выбранным примером. Не запускай оба примера одновременно.
4. Открой Output, очисти старые сообщения и запусти Test.
5. Сравни сообщения с соответствующим файлом `.expected.txt`. Время, пометка Server и имя скрипта не являются частью ожидаемого текста.

| Пример | Содержание | Ожидаемый вывод |
| --- | --- | --- |
| [01_basics_demo.luau](01_basics_demo.luau) | 20 коротких примеров из урока: вывод, переменные, типы, операторы, условия, циклы, функции и области видимости. | [01_basics_demo.expected.txt](01_basics_demo.expected.txt) |
| [02_expedition.luau](02_expedition.luau) | Общая практика «Отчёт об экспедиции» с настройками в начале файла. | [02_expedition.expected.txt](02_expedition.expected.txt) |

В первом файле независимые примеры отделены конструкцией `do ... end`. Она выполняет тело один раз и создаёт отдельную локальную область видимости. Это позволяет использовать одинаковые учебные имена в разных примерах. При запуске одного блока из текста урока такая оболочка не нужна.

Общий вывод первого файла идёт в порядке примеров. Если Studio сворачивает повторяющиеся сообщения, учитывай счётчик повторов в Output или запускай соответствующие блоки по одному.

## Самостоятельные изменения

В примере экспедиции по очереди проверь VIP, ноль раундов, нулевую награду и точное равенство цели. Между опытами возвращай исходные значения. Ожидаемые результаты находятся в разделе практики основного урока.

Не используй эти файлы как готовые решения домашней работы: у домашних задач отдельные условия и требования к результату.

## Что проверено при подготовке

- Все **21** обычный запускаемый пример из текста выполнен официальным [Luau CLI 0.745](https://github.com/luau-lang/luau/releases/tag/0.745); вывод сравнен с образцом. Из них 20 объединены в первый файл, один сохранён как практика экспедиции.
- Объединённый файл выполнен целиком, его вывод совпал с `01_basics_demo.expected.txt`.
- Проверены четыре изменения настроек экспедиции из таблицы в уроке.
- Проверено, что намеренно ошибочный по смыслу пример домашней задачи 5 действительно печатает 14 и 20.
- Анализатор `luau-analyze` не обнаружил ошибок типов в двух файлах примеров. Он выдал одно предупреждение LocalShadow: в примере затенения внутренняя coins специально скрывает внешнюю. Это поведение разбирается в уроке.

Эта проверка подтверждает выполнение кода и ожидаемые сообщения. Она не заменяет прохождение урока учеником или проверку расположения окон в конкретной версии Studio. Установка CLI для прохождения урока не требуется: основной способ запуска — Roblox Studio.
