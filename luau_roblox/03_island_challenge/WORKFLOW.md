# Производственный процесс материалов

## Этапы

1. **Методист** фиксирует аудиторию, цель занятия, продукт, диагностику и дифференциацию.
2. **Исследователь Roblox** сверяет термины, пути UI и технические утверждения с официальными источниками; добавляет ссылку и дату проверки.
3. **Исследователь курсов** сравнивает задачу с официальными учебными планами и предлагает удачные педагогические приёмы, не копируя чужие тексты и медиа.
4. **Автор материалов** пишет сценарий занятия, код, подсказки, лист ученика и критерии завершения.
5. **Автор скриншотов** делает собственные снимки своей проверенной версии Studio, подписывает нужные панели/объекты и проверяет читаемость. Не вставляет чужие скриншоты без разрешения/лицензии.
6. **Автор видео** записывает самостоятельную демонстрацию конкретного шага, монтирует короткими главами, добавляет субтитры и маркирует версию интерфейса.
7. **GitHub-агент** раскладывает материалы по структуре, удаляет временные файлы, проверяет ссылки и дифф, затем готовит commit/PR в указанный репозиторий.

## Критерии приёмки любого занятия

- Понятно, что ученик сможет сделать к концу.
- Новые понятия объяснены до кода.
- Код протестирован в Roblox Studio, а известные ограничения зафиксированы.
- Есть путь помощи для отстающего ученика и расширение для быстрого.
- Есть проверки понимания, а не только инструкции «скопируй-вставь».
- Скриншоты и видео совпадают с текущим интерфейсом и проверенным проектом.
- Все сторонние ассеты и исходники имеют понятное происхождение и допустимы к использованию.

## Актуальность

Перед выпуском и при изменении Studio пересматривайте интерфейсные шаги, поведение скриптов и API. Для Luau/Engine API сначала используйте Creator Hub. Не переносите старый Lua-код без проверки совместимости. Указывайте дату последней проверки в каждом уроке.
