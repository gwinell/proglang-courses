# Семь специализированных ролей

Файлы ниже — готовые инструкции для повторного запуска ролей в отдельной задаче Codex или другой агентной системе. Два исследовательских субагента были запущены для подготовки этого курса. Они завершили свои задачи и не являются постоянно работающими агентами. В этой среде нет инструмента для регистрации семи постоянных агентов в аккаунте Codex, поэтому роли сохранены как переносимые инструкции.
