# Чек-лист съёмки скриншотов для занятия 1

**Состояние на 25.10.2026:** в папке курса пока нет файла проекта Roblox Studio и исходных скриншотов. Установленное приложение RobloxStudio обнаружено, но попытка открыть окно через доступный интерфейс управления завершилась тайм-аутом. Поэтому этот пакет не содержит искусственно нарисованных «скриншотов Studio».

Когда проект будет открыт в Roblox Studio, сделайте реальные кадры:

1. **`01-studio-overview.png`** — полный вид окна: Viewport, Explorer, Properties. Показать сцену с выбранным `Part`.
2. **`02-script-location.png`** — Explorer с раскрытым `ServerScriptService` и созданным `WelcomeScript`. Не включать личный профиль/аккаунт.
3. **`03-script-editor.png`** — редактор с коротким `print("Добро пожаловать!")`; текст должен быть крупным, а весь код — читаемым.
4. **`04-output-result.png`** — Output после запуска, где виден результат `print`; по возможности оставить рядом Explorer с расположением скрипта.

## Перед публикацией

- Проверьте, что Studio не показывает личные данные, сообщения или приватные идентификаторы.
- Убедитесь, что снимок совпадает с точными именами объектов в уроке.
- Не добавляйте стрелки поверх элементов, пока не сохранён исходник кадра.
- Добавьте к каждому снимку короткую подпись: что найти и что нажать.
- Проверьте читаемость при ширине изображения около 900 px.
- Сохраните оригинальный кадр и размеченную копию отдельно.
