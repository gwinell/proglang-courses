# Luau и Roblox Studio

Материалы для начинающих: сначала знакомимся с редактором, затем изучаем язык Luau и применяем его к объектам игры.

## С чего начать

**[Урок 1. Знакомство с Roblox Studio](00_start/01_studio_basics.md)** — проект Baseplate, Explorer и Properties, управление камерой, создание деталей, перемещение, размер и поворот, закрепление, столкновения, группировка, запуск и сохранение сцены.

В уроке есть десять иллюстраций из официального репозитория Roblox, пошаговая практика «Тренировочная дорожка», домашняя работа «Площадка для исследователя», подсказки и критерии проверки. Программировать для первого занятия не требуется.

**[Урок 2. Основы Luau](01_basics/02_luau_basics.md)** — переменные, типы данных, операторы, условия, циклы for/while/repeat, функции, параметры, return и области видимости.

Второй урок разделён на три части для последовательного прохождения. В нём есть шесть иллюстраций из Roblox/creator-docs и luau-lang/site, таблицы выполнения по шагам, [запускаемая практика](01_basics/examples/02_expedition.luau), пять обязательных домашних задач и дополнительное задание. Начни с раздела о Script и Output, даже если уже читал короткий конспект Luau.

## Как заниматься

1. Прочитай небольшой раздел и повтори действие в Studio.
2. Предскажи результат, измени одну настройку и проверь предположение.
3. Объясни своими словами, что изменилось и почему.
4. Выполни домашнюю работу самостоятельно и проверь её по списку в уроке.

Проекты запускаются в Roblox Studio на Windows или macOS. Markdown-файлы удобно читать прямо на GitHub. Изображения хранятся в репозитории; источники и условия использования указаны отдельно для [урока 1](assets/studio-lesson-01/SOURCES.md) и [урока 2](assets/luau-lesson-02/SOURCES.md).
