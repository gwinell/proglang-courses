# Конспект урока: Основы Python

## 1. `print()`

Функция `print()` используется для вывода информации на экран.

### Примеры

```python
print("Привет, мир!")
print(10)
print(2 + 3)
```

Можно выводить несколько значений одновременно:

```python
print("Возраст:", 18)
print("Сумма:", 10 + 5)
```

---

## 2. Параметр `sep`

Параметр `sep` (от *separator* — разделитель) определяет, что будет находиться между несколькими значениями, переданными в `print()`.

По умолчанию используется пробел:

```python
print("Python", "Java", "C++")
```

Результат:

```text
Python Java C++
```

Можно задать собственный разделитель:

```python
print("Python", "Java", "C++", sep=", ")
```

Результат:

```text
Python, Java, C++
```

Ещё один пример:

```python
print(2026, 8, 21, sep="-")
```

Результат:

```text
2026-8-21
```

---

## 3. Параметр `end`

Параметр `end` определяет, что будет добавлено в конце вывода.

По умолчанию `print()` заканчивает вывод переходом на новую строку:

```python
print("Привет")
print("Мир")
```

Результат:

```text
Привет
Мир
```

Если изменить `end`, можно продолжить вывод в той же строке:

```python
print("Привет", end=" ")
print("Мир")
```

Результат:

```text
Привет Мир
```

Можно использовать и другие символы:

```python
print("Hello", end="!")
```

Результат:

```text
Hello!
```

## 4. `input()`

Функция `input()` используется для получения данных от пользователя.

```python
name = input()
print(name)
```

Можно добавить подсказку:

```python
name = input("Введите имя: ")
print(name)
```

### Важный момент

`input()` всегда возвращает строку (`str`), даже если пользователь ввёл число.

Например:

```python
age = input("Введите возраст: ")
```

Переменная `age` будет содержать строку.

Если нужно получить число, используется преобразование типа:

```python
age = int(input("Введите возраст: "))
```

Для дробного числа:

```python
price = float(input("Введите цену: "))
```

## 5. Переменные

Переменная — это имя, которое используется для хранения значения.

Пример:

```python
name = "Алекс"
age = 18
```

Здесь:

- `name` хранит строку `"Алекс"`;
- `age` хранит число `18`.

Значение переменной можно использовать в программе:

```python
name = "Алекс"
age = 18

print(name)
print(age)
```

Значение переменной можно изменить:

```python
age = 18
age = 19

print(age)
```

Результат:

```text
19
```

### Правила именования переменных

Хорошие примеры:

```python
name = "Alex"
user_age = 18
total_price = 100
```

Не следует начинать имя переменной с цифры:

```python
# Неправильно
2name = "Alex"
```

Для составных имён удобно использовать стиль `snake_case`:

```python
user_name = "Alex"
student_age = 18
```

## 6. F-строки

F-строки используются для удобной вставки значений переменных внутрь текста.

Перед строкой ставится буква `f`:

```python
name = "Алекс"
age = 18

print(f"Меня зовут {name}, мне {age} лет.")
```

Результат:

```text
Меня зовут Алекс, мне 18 лет.
```

В фигурных скобках `{}` можно указывать переменные и выражения:

```python
a = 10
b = 5

print(f"Сумма: {a + b}")
```

Результат:

```text
Сумма: 15
```

F-строки особенно удобны, когда нужно вывести сразу несколько значений:

```python
name = input("Введите имя: ")
age = int(input("Введите возраст: "))

print(f"Привет, {name}! Тебе {age} лет.")
```

## 7. Пример программы, объединяющей изученные темы

```python
name = input("Введите ваше имя: ")
age = int(input("Введите ваш возраст: "))

print("Информация о пользователе:")
print("Имя", "Возраст", sep=" | ")
print(name, age, sep=" | ")

print(f"Привет, {name}! Тебе {age} лет.", end=" ")
print("Добро пожаловать в Python!")
```

В этой программе используются:

- `input()` — получение данных от пользователя;
- переменные — хранение имени и возраста;
- `int()` — преобразование возраста в число;
- `print()` — вывод информации;
- `sep` — разделитель между значениями;
- `end` — управление окончанием строки;
- f-строка — удобная вставка переменных в текст.

## Что нужно запомнить

| Конструкция | Назначение |
|---|---|
| `print()` | Вывод информации на экран |
| `sep` | Разделитель между значениями в `print()` |
| `end` | Определяет, что будет в конце `print()` |
| `input()` | Получение данных от пользователя |
| `=` | Присваивание значения переменной |
| `int()` | Преобразование в целое число |
| `float()` | Преобразование в дробное число |
| `f"..."` | Форматирование строк с переменными |
| `{variable}` | Вставка значения переменной в f-строку |
