## Домашние задания и повторение

Домашняя работа полностью находится в конце каждого из 19 блокнотов, включая дополнительные уроки. В каждом условии есть сюжет, точное требование, ограничения, таблица формата входных и выходных данных и таблица примеров. После задачи расположена ячейка для решения. Для функций таблицы описывают аргументы и результат, для файлов и проектов — файлы, команды и ожидаемые изменения.

Весь банк содержит 151 задачу. Это запас практики на несколько занятий: выполняй обязательные задачи и повторение, а дополнительные выбирай с преподавателем. [Указатель ДЗ](homework/README.md) ведёт к самим блокнотам. Переходить на отдельную страницу за условием не требуется. Планируй повторения по [реестру навыков](homework/review_schedule.md); [банк коротких вопросов](homework/review_tasks.md) используй для устной диагностики на занятии.

## Как запускать

Для основной линии подходят Python 3.10+ и Jupyter Notebook / JupyterLab. Код использует стандартную библиотеку Python; `%%writefile` — команда Jupyter для записи модуля в файл. В обычный `.py` её не вставляют: нужно создать файл вручную. Для первой локальной установки с Pygame используй версии, указанные в руководстве проекта.

Запускай ячейки сверху вниз. Упражнения со строкой `# Напиши решение здесь` заполняй самостоятельно. Намеренные ошибки предложены в комментариях: убирай `#` только для соответствующего эксперимента.

Для Google Colab ссылка имеет вид `https://colab.research.google.com/github/gwinell/proglang-courses/blob/main/путь_к_блокноту`. Новые изменения появятся там после загрузки в ветку `main`. Блокноты и картинки также можно открыть из скачанной копии курса. Относительные пути к изображениям проверены локально; отображение файлов репозитория в конкретной версии Colab отдельно не проверялось.
