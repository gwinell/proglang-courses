# Самостоятельные контрольные: варианты

Материал для преподавателя. Выдавай ученику только один вариант соответствующей контрольной точки. Полные решения новых задач заранее не показывать. На каждую работу отводится 35–45 минут; скорость не оценивается. Все задачи решаются на уже пройденных темах. Разрешены корректные альтернативные реализации.

## Общие правила проведения

1. Ученик сначала пересказывает вход, результат и особые случаи.
2. В части «исправление» нужно указать ошибочную строку и объяснить, почему она нарушает условие.
3. Самостоятельную задачу нужно проверить на обычном и граничном примере.
4. В конце ученик объясняет один выбор в алгоритме. Если застрял, преподаватель записывает, какая подсказка помогла.

Каждая из четырёх частей оценивается отдельно по шкале 0–3 из документа [рубрики оценивания](ASSESSMENT_AND_RUBRICS.md). Отметка о навыке важнее общей суммы.

### 2. Найди и исправь ошибку

Музей выдаёт бесплатный билет детям младше 7 лет и посетителям, которым уже исполнилось 65 лет. Остальным нужен обычный билет. Программа должна вывести `free` или `regular`.

```python
age = int(input())
if age < 7 and age >= 65:
    print("free")
else:
    print("regular")
```

Покажи исправленный код. Проверь возраст 6, 7, 65 и 66.

### 3. Реши самостоятельно

**Сюжет.** В мастерской выдают номер заказа. Каждый жетон печатает номер и его последнюю цифру, чтобы посетитель мог проверить жетон.

**Задача.** По целому неотрицательному номеру `n` выведи последнюю цифру числа.

**Формат данных**

| Входные данные | Выходные данные |
|---|---|
| Одна строка — целое число `n`. | Одна цифра — остаток от деления `n` на 10. |

**Ограничения.** `0 ≤ n ≤ 10^9`.

**Примеры**

| Входные данные | Выходные данные |
|---|---|
| `482` | `2` |
| `0` | `0` |

Напиши программу со стандартным вводом и выводом. Не печатай поясняющий текст.

### 4. Объясни

Почему `input()` сам по себе не даёт целое число? Что выведет `7 / 2`, а что — `7 // 2`?

### Критерии

- Часть 1: вывод `2 17`; смысл частного и остатка объяснён — 1 балл.
- Часть 2: заменён `and` на логически подходящее условие; корректны обе границы 7 и 65 — до 3 баллов.
- Часть 3: считывает `n`, использует корректную арифметику, выводит только цифру; работает для 0 — до 3 баллов.
- Часть 4: отделяет текстовый ввод от числа; верно объясняет `/` и `//` — до 3 баллов.

### 3. Реши самостоятельно

**Сюжет.** Секретарь записал время ожидания посетителей в минутах. Руководителю нужен список тех значений, которые не превышают установленный предел, и их количество.

**Задача.** Прочитай сначала целое число `n`, затем `n` целых времён, затем предел `limit`. Выведи подходящие времена в исходном порядке одной строкой через пробел, затем их количество. Если подходящих значений нет, первая строка должна быть пустой.

**Формат данных**

| Входные данные | Выходные данные |
|---|---|
| Первая строка: `n`. Вторая строка: `n` целых чисел. Третья строка: `limit`. | Первая строка: числа `≤ limit` в прежнем порядке через пробел (или пустая строка). Вторая строка: количество выбранных чисел. |

**Ограничения.** `0 ≤ n ≤ 100`; `0 ≤ время, limit ≤ 10 000`.

**Примеры**

| Входные данные | Выходные данные |
|---|---|
| <pre>5<br>8 12 4 12 6<br>8</pre> | <pre>8 4 6<br>3</pre> |
| <pre>3<br>9 10 11<br>5</pre> | <pre><br>0</pre> |

### 4. Объясни

Чем индекс отличается от значения элемента? Почему здесь удобно создать новый список, а не удалять неподходящие значения из старого?

### Критерии

- Часть 1: таблица содержит суммы 3, 8, 10 и объясняет обновление накопителя — до 2 баллов.
- Часть 2: обнаружен сдвиг индексов; решение не портит исходный список — до 3 баллов.
- Часть 3: порядок сохраняется; учитывается пустой результат и `n = 0`; формат ровно из двух строк — до 3 баллов.
- Часть 4: индекс/значение и причина отдельного списка объяснены — до 2 баллов.

### 3. Реши самостоятельно

**Сюжет.** В чате нужно подсчитать, сколько сообщений каждого участника попало в журнал. Имена уже очищены от пробелов по краям.

**Задача.** Реализуй функцию `count_messages(names)`, которая принимает список строк и возвращает словарь `имя → количество сообщений`. Пустой список должен дать пустой словарь.

**Формат данных**

| Входные данные | Выходные данные |
|---|---|
| Один аргумент `names`: список строк; одинаковые строки обозначают одного участника. | Возвращаемый словарь со счётчиком для каждого встретившегося имени. Функция ничего не печатает и не меняет исходный список. |

**Ограничения.** До 100 строк; каждая строка непустая.

**Примеры**

| Входные данные | Выходные данные |
|---|---|
| `count_messages(["Ася", "Лев", "Ася"])` | `{"Ася": 2, "Лев": 1}` |
| `count_messages([])` | `{}` |

### 4. Объясни

Почему для проверки равенства строк обычно используют `==`, а не `is`? Для чего словарю нужен ключ?

### Критерии

- Часть 1: вызов передаёт `100` и `0.1`, результат `110.0`; отличает печать от возвращения — до 2 баллов.
- Часть 2: сравнение заменено на равенство, результат возвращается, пустой список даёт 0 — до 3 баллов.
- Часть 3: правильные частоты, пустой ввод, нет печати и мутации аргумента — до 3 баллов.
- Часть 4: различие идентичности и равенства, назначение ключа — до 2 баллов.

### 3. Реши самостоятельно

**Сюжет.** Класс ведёт счётчик посещений. В один день один объект счётчика используется для нескольких отметок, а другой объект должен вести отдельный счёт.

**Задача.** Создай класс `VisitCounter` с экземплярным атрибутом `value`, изначально равным 0. Метод `add()` увеличивает его на 1. Метод `reset()` устанавливает значение 0. Метод `__str__()` возвращает строку `Посещения: N`. Создай два объекта, вызови `add()` для первого три раза, выведи оба объекта, затем сбрось первый и снова выведи оба.

**Формат данных**

| Входные данные | Выходные данные |
|---|---|
| Ввод отсутствует. Программа выполняет последовательность методов, указанную в условии. | Четыре строки: первый и второй счётчики после трёх добавлений, затем оба после сброса первого. |

**Пример ожидаемого вывода**

| Входные данные | Выходные данные |
|---|---|
| Нет ввода | <pre>Посещения: 3<br>Посещения: 0<br>Посещения: 0<br>Посещения: 0</pre> |

### 4. Объясни

Почему `value` должен создаваться в `__init__` через `self.value`, а не быть общим изменяемым атрибутом класса? Как проверить, что `reset()` не сбрасывает другой экземпляр?

### Критерии

- Часть 1: вывод `3 0`; объяснено независимое состояние экземпляров — до 2 баллов.
- Часть 2: файл закрывается автоматически и лишние переводы строки убраны — до 3 баллов.
- Часть 3: `add`, `reset`, `__str__` соответствуют контракту; два объекта независимы — до 3 баллов.
- Часть 4: объяснена принадлежность состояния объекту и предложена проверка второго экземпляра — до 2 баллов.
