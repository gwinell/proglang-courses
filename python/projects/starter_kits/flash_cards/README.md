# Стартовый набор: «Карточки для повторения»

Консольная адаптация идеи Flash Card App Capstone, Day 31 курса 100 Days of Python. Исходная идея проекта использует интерфейс и дополнительные библиотеки; этот учебный вариант работает в стандартном Python и читает локальный CSV. Описание проекта — в [проектной паре 6](../../06_files.md).

## Файлы и запуск

- `cards.csv` — готовая UTF-8 таблица из пяти карточек с заголовком `question,answer`.
- `stage_1_read.py` — запуск: `python stage_1_read.py`; читает и печатает карточки.
- `main.py` — каркас раунда, проверки ответа и записи результата.
- `results.txt` — создаётся программой только после завершения непустого раунда.

Работай из этой папки. Не перезаписывай `cards.csv`. Для простоты поле ответа в этом наборе не содержит запятых и кавычек; `csv.DictReader` всё равно нужно использовать, чтобы читать строки по именам колонок.

## Этапы

1. Запусти этап чтения и объясни, почему каждая строка становится словарём.
2. В `main.py` загрузи строки CSV. Если список пуст, выведи `Пока нечего повторять.` и заверши программу без создания отчёта.
3. Показывай по одному вопросу. Ответ сравнивай после `strip().lower()` с тем же преобразованием правильного ответа.
4. Посчитай правильные ответы и после каждого ответа покажи правильный ответ, если ученик ошибся.
5. В конце запиши в UTF-8 файл `results.txt` одну строку `Верно: N из M`.
6. Проверь повторный запуск: результат должен соответствовать только текущему раунду и не дописываться к старому.

## Приёмка

- Пять строк читаются, заголовок не считается карточкой.
- Сравнение игнорирует регистр и пробелы в начале/конце.
- На ошибке показан верный ответ, а программа переходит к следующей карточке.
- Итог `N` находится между 0 и количеством карточек.
- Пустой файл с одним заголовком не создаёт `results.txt`.
- `cards.csv` остаётся неизменным после любого числа запусков.
