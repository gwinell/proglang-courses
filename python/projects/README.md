# Проектная линия курса Python

Каталог содержит по два проекта на каждый крупный блок: один проходит вместе с преподавателем, второй ученик выполняет дома самостоятельно. Это адаптации идей проектов Angela Yu «100 Days of Code: The Complete Python Pro Bootcamp» под порядок и уже изученные инструменты курса.

## Маршрут

|---|---|---|---|
| Ввод, числа, условия | Чаевые и счёт | Остров сокровищ | [01 — Основы](01_basics.md) |

## Как работать с проектной парой

- Проект на уроке — совместное планирование, сборка короткими шагами и демонстрация того, как проверять гипотезы. Учитель использует раздел «Ход урока» и может подготовить свою реализацию отдельно.
- Домашний проект — самостоятельная постановка плана, реализация и проверка по критериям. В ученической карточке нет полного алгоритма или готового решения. Даны две подсказки с постепенным раскрытием.
- Перед проектом преподаватель проверяет предпосылки в таблице соответствующего блока. Если ученик ещё не изучил while, random, функции, классы или файлы, нельзя делать их скрытым обязательным условием.
- После проекта ученик демонстрирует программу, объясняет один фрагмент, показывает граничный тест и вносит небольшое изменение требования.
