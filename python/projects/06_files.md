# Проектная пара 6. Файлы и сохранение данных

## На уроке: «Письмо каждому участнику клуба»

**Источник:** Mail Merge, Day 24: [индекс ashutoshkrris](https://github.com/ashutoshkrris/100-Days-of-Python#day-24---files-directories-and-paths); конкретные [Day24 README](https://github.com/Mikerniker/100_Days_of_Python/blob/main/Day24/README.md) и [Day24/main.py](https://github.com/Mikerniker/100_Days_of_Python/blob/main/Day24/main.py). Проверены шаблон, список имён, замена маркера и пакетная запись отдельных файлов.

**Сюжет:** руководитель клуба готовит персональное приглашение каждому участнику. Текст письма общий; меняется имя.

**Предпосылки:** with open, чтение/запись текстовых файлов, readlines, strip, replace, относительные пути. Перед уроком объяснить UTF-8.

**Данные:** файл templates/invitation.txt с маркером {name}; data/names.txt — имя на строке; каталог out/. Имена могут быть кириллическими, состоять из нескольких слов; пустые строки игнорируются.

**Минимум:** прочитать шаблон один раз; для каждого непустого имени заменить все маркеры; записать invitation_1.txt, invitation_2.txt и т.д.; показать число созданных файлов. Повторяющиеся имена получают отдельные файлы.

**Пример:** шаблон «Здравствуйте, {name}! Приходите в клуб.» и строки «Анна Смирнова», «Марк» дают два файла с соответствующими именами.

**План занятия:** посмотреть структуру; прочитать один шаблон; изучить результат readlines и strip; собрать один текст; добавить цикл и номер в имени файла; записать результат; перечитать его; обработать все строки.

**Критерии и проверки:** число файлов равно числу непустых имён; все маркеры заменены; UTF-8 текст цел; исходники не перезаписаны. Сначала протестировать один адресат, затем два, затем пустые строки и повторяющееся имя. Ученик показывает путь от строки входа к итоговому файлу.

**Расширение:** добавить тему письма; проверить отдельно безопасность имён в путях. Без дополнительных пакетов.

**Адаптация:** та же идея персональной подстановки; свои имя маркера, директории и русские данные. Письма, текст README и исходная реализация не копируются.

## Дома: «Карточки для пятиминутного повторения»

[Стартовый набор проекта: CSV из пяти карточек, пример чтения и каркас раунда](starter_kits/flash_cards/README.md).

**Источник:** Flash Card App Capstone, Day 31 в [указателе ashutoshkrris](https://github.com/ashutoshkrris/100-Days-of-Python#day-31---flash-card-app-capstone-project); детали проверены по [Day31 README](https://github.com/Mikerniker/100_Days_of_Python/blob/main/Day31/README.md) и [Day31/main.py](https://github.com/Mikerniker/100_Days_of_Python/blob/main/Day31/main.py). Исходная версия использует Tkinter, pandas и CSV. Домашнее задание — console-only вариант без этих технологий.

**Сюжет:** ученик повторяет термины по карточкам, не перечитывая конспект. Вопросы и ответы лежат в файле; после раунда программа сохраняет результат.

**Предпосылки:** файлы, строки, список/словарь, цикл, случайность. Функции используются, если пройдены. Внешние пакеты не требуются. Учитель выдаёт небольшой UTF-8 CSV с колонками question,answer.

**Минимум:** прочитать карточки; перемешать порядок; показать вопросы по одному; принять ответ; сравнить без учёта регистра и пробелов по краям; на ошибку показать правильный ответ; в конце записать число верных ответов и общее число в results.txt. Каждая карточка показывается один раз.

**Вход и границы:** пустой CSV выводит «пока нечего повторять», не пишет фиктивный результат 0 из 0. Ошибка ответа не останавливает игру. Исходные карточки не изменяются.

**Пример:** из трёх карточек два верных ответа дают файл с текстом «Верно: 2 из 3». Для повторяемой проверки порядок можно временно фиксировать.

**Подсказки:**
1. Сначала проверь чтение одной строки файла и извлечение вопроса/ответа.
2. Нормализуй оба текста одинаково, а отчёт записывай после завершения цикла.

**Сдача и критерии:** файл программы, небольшой CSV и результат запуска. Верно считаются ответы; пробелы и регистр не влияют; пустой файл обработан по правилу; исходные данные целы; повторный запуск проходит.

**Повторение:** with open, CSV, список словарей, strip, lower, цикл, счётчик, проверка пустой коллекции. Расширение — отдельный список карточек, на которые ученик ответил неверно, для будущего повторения.

**Адаптация:** идея карточек взята из проекта Day 31, но интерфейс консольный, данные небольшие и задаются учителем. Не используется GUI, pandas или исходный набор данных. Код и графика первоисточника не копируются.
