# Пошаговая отладка в Python

В уроке об ошибках уже разобраны traceback, временные `print()` и порядок поиска причины. Здесь научимся приостанавливать программу и проверять состояние по шагам. Понадобится Python 3 и возможность запустить файл из терминала. Графический интерфейс отладчика зависит от редактора, поэтому инструкция использует стандартный отладчик Python `pdb`.

## Результаты

После практики ты сможешь остановить программу в выбранной точке, выполнить следующую строку, посмотреть значение переменной, войти внутрь функции и продолжить до следующей остановки. Ты также сможешь объяснить, на какой строке состояние впервые стало неправильным.

## 1. Подготовь файл

Создай файл `debug_demo.py` и скопируй пример. Функция должна прибавить к `total` числа списка, а затем вернуть сумму.

```python
def calculate_total(numbers):
    total = 0
    for number in numbers:
        breakpoint()
        total = total + number
    return total


scores = [4, 5, 3]
answer = calculate_total(scores)
print(answer)
```

`breakpoint()` временно остановит выполнение. Запусти файл в терминале:

```text
python debug_demo.py
```

Если команда `python` не найдена, попробуй согласованную в классе команду запуска Python (например, `python3 debug_demo.py`) и попроси преподавателя помочь настроить среду. Не устанавливай случайные пакеты для этого урока: `pdb` входит в стандартную поставку Python.

## 2. Команды отладчика

После остановки появится приглашение `(Pdb)`. Введи команду и нажми Enter. Команды можно сокращать до первой буквы.

| Команда | Действие |
|---|---|
| `n` или `next` | Выполнить текущую строку и остановиться на следующей строке этого уровня |
| `p total` | Показать значение выражения `total` |
| `p number` | Показать текущий элемент цикла |
| `s` или `step` | Выполнить текущую строку, входя внутрь вызванной функции |
| `c` или `continue` | Продолжить выполнение до следующего `breakpoint()` или конца программы |
| `q` или `quit` | Завершить отладку |

Введи `p total` и `p number`. Затем нажми `n` несколько раз и снова посмотри значения. Перед суммированием `total` равен 0, затем 4, затем 9. В конце напечатается 12.

Поскольку `breakpoint()` стоит внутри цикла, программа остановится на каждом элементе. Когда закончил исследовать один проход, нажми `c`, чтобы дойти до следующей остановки. Чтобы закончить работу и получить обычный запуск, удали `breakpoint()` или закомментируй строку.

## Ограничения и безопасность

- В интерактивной среде Jupyter команды отладчика могут работать иначе, чем в отдельном файле. Для этого урока используй файл, запущенный в терминале.
- Во время остановки программа ждёт твою команду; это не бесконечный цикл. Нажми `c` или `q`.
- Отладчик выполняет код как обычно. Проверяй подозрительные операции на учебных данных и не запускай неизвестные программы.
- Для объяснения состояния используй только уже изученные данные и переменные. Стек и внутренние подробности Python пока не нужны.
