## Глава 1. Повторяем пройденное

### 1.1. Вывод на экран

Компьютер умеет показывать текст на экране с помощью команды `print()`.

```python
print("Привет!")
print("Мне", 12, "лет")
```

`print` может выводить сразу несколько вещей через запятую. Между ними автоматически ставится пробел.

### 1.2. Ввод от пользователя

Программа может задавать вопросы и получать ответы.

```python
name = input("Как тебя зовут? ")
```

Важно запомнить: `input()` **всегда** возвращает строку, то есть текст. Даже если пользователь ввёл число 12, программа получит текст `"12"`.

Если из ввода нужно получить число, используют функцию `int()`:

```python
age = int(input("Сколько тебе лет? "))
```

### 1.3. Переменные

Переменная — имя, связанное с объектом. Представь ярлык со стрелкой к значению: присваивание может направить его к другому объекту. Несколько имён могут ссылаться на один объект.

```python
name = "Аня"
age = 12
```

Переменные можно использовать в `print`:

```python
print("Привет,", name)
print("Через год тебе будет", age + 1)
```

## Глава 2. Цикл `for`

Цикл `for` позволяет повторить один и тот же блок команд несколько раз.

### 2.1. Повторить текст 5 раз

```python
for i in range(5):
    print("Привет!")
```

`range(5)` даёт числа 0, 1, 2, 3, 4 — итого 5 повторений.

### 2.2. Использовать переменную цикла

```python
for i in range(5):
    print("Это строка номер", i)
```

Выведет:

```
Это строка номер 0
Это строка номер 1
Это строка номер 2
Это строка номер 3
Это строка номер 4
```

### 2.3. Повторить символ в одну строку

```python
symbol = "*"
for i in range(10):
    print(symbol, end="")
```

Параметр `end=""` говорит `print` не переходить на новую строку. Результат:

```
**********
```

### 2.4. Комбинируем всё вместе

```python
name = input("Как тебя зовут? ")
n = int(input("Сколько раз поздороваться? "))

for i in range(n):
    print("Привет,", name + "!")
```

Программа:
1. Спрашивает имя.
2. Спрашивает, сколько раз повторить.
3. Повторяет приветствие нужное количество раз.

## Глава 3. Условные конструкции

До сих пор наши программы выполнялись строго сверху вниз: каждая строка выполнялась одна за другой. Но часто нужно, чтобы программа действовала по-разному в зависимости от ситуации.

Например:
- Если пользователь ввёл правильный пароль — пустить его.
- Если возраст меньше 18 — написать "доступ запрещён".
- Если число чётное — написать "чётное", иначе — "нечётное".

Для таких случаев в Python есть условные конструкции.

### 3.1. Простое условие `if`

Конструкция `if` проверяет условие. Если условие истинно, то выполняется блок кода под `if`. Если ложно — блок пропускается.

```python
age = int(input("Сколько тебе лет? "))

if age >= 18:
    print("Ты совершеннолетний")
```

Как это работает:

```
        НАЧАЛО
          │
          ▼
    Введи возраст
          │
          ▼
   Возраст >= 18?
         / \
       ДА   НЕТ
       /      \
      ▼        ▼
 "Ты совершен-   (ничего
 нолетний"       не выводим)
          │
          ▼
       КОНЕЦ
```

Важно: после условия ставится двоеточие `:`, а следующие строки, относящиеся к `if`, пишутся с отступом в 4 пробела.

### 3.2. Операторы сравнения

Чтобы составлять условия, используют операторы сравнения:

| Оператор | Значение           | Пример  | Результат |
|----------|--------------------|---------|-----------|
| `==`     | равно              | `5 == 5` | `True`    |
| `!=`     | не равно           | `5 != 3` | `True`    |
| `>`      | больше             | `7 > 4`  | `True`    |
| `<`      | меньше             | `7 < 4`  | `False`   |
| `>=`     | больше или равно   | `5 >= 5` | `True`    |
| `<=`     | меньше или равно   | `3 <= 5` | `True`    |

> Обрати внимание: для сравнения используется два знака равно `==`, а для присваивания — один `=`.

### 3.3. Условие `if-else`

Если нужно выбрать одно из двух действий, используют `else` (иначе).

```python
number = int(input("Введи число: "))

if number % 2 == 0:
    print("Число чётное")
else:
    print("Число нечётное")
```

Знак `%` — это оператор остатка от деления. `number % 2` равно 0, если число делится на 2 без остатка, то есть чётное.

```
        НАЧАЛО
          │
          ▼
    Введи число
          │
          ▼
  Число чётное?
         / \
       ДА   НЕТ
       /      \
      ▼        ▼
"Число      "Число
 чётное"    нечётное"
          │
          ▼
       КОНЕЦ
```

### 3.4. Условие `if-elif-else`

Если вариантов больше двух, используют `elif` (сокращение от else if — "иначе если").

```python
score = int(input("Сколько баллов? "))

if score >= 90:
    print("Отлично!")
elif score >= 75:
    print("Хорошо")
elif score >= 60:
    print("Удовлетворительно")
else:
    print("Нужно подучиться")
```

Программа проверяет условия сверху вниз. Как только находит первое истинное условие, выполняет соответствующий блок и дальше не идёт.

### 3.5. Проверка строк

Со строками тоже можно сравнивать:

```python
answer = input("Какой сейчас год? ")

if answer == "2026":
    print("Правильно!")
else:
    print("Подумай ещё")
```

### 3.6. Вложенные условия

Условия можно вкладывать одно в другое. Но не увлекайся — чем меньше уровней вложенности, тем проще читать код.

```python
age = int(input("Сколько тебе лет? "))

if age >= 6:
    if age <= 17:
        print("Ты школьник")
    else:
        print("Ты уже взрослый")
else:
    print("Ты ещё не ходишь в школу")
```

### 3.7. Совмещаем `if` и `for`

Цикл `for` перебирает значения, а `if` внутри него проверяет каждое значение.

```python
for i in range(1, 11):
    if i % 2 == 0:
        print(i, "- чётное")
    else:
        print(i, "- нечётное")
```

Эта программа проверит числа от 1 до 10 и напишет, какие из них чётные, а какие — нет.

### 3.8. Досрочный выход из цикла: `break`

Иногда нужно прервать цикл раньше, чем он закончится сам. Для этого используется команда `break` (англ. "разорвать").

```python
secret = "python"

for i in range(3):
    guess = input("Угадай секретное слово: ")
    if guess == secret:
        print("Правильно!")
        break
    else:
        print("Неправильно, попробуй ещё раз")
```

Как только выполняется `break`, цикл немедленно останавливается, и программа идёт дальше.

### 3.9. Типичные ошибки

1. **Забыли двоеточие**

   ```python
   if age > 18  # ошибка!
       print("OK")
   ```

2. **Использовали `=` вместо `==` в условии**

   ```python
   if age = 18:  # ошибка!
       print("18 лет")
   ```

3. **Забыли отступы**

   ```python
   if age > 18:
   print("OK")  # ошибка!
   ```

4. **Сравнивают строку с числом**

   ```python
   age = input("Сколько лет? ")  # age — строка
   if age > 18:  # ошибка!
       print("OK")
   ```

   Нужно преобразовать в число: `age = int(input("Сколько лет? "))`.

## Глава 4. Что запомнить

- `input()` возвращает строку.
- `int()` превращает строку в число.
- `range(n)` повторяет действие n раз.
- `print(..., end="")` печатает без переноса строки.
- `if` проверяет условие.
- `else` выполняется, если условие ложно.
- `elif` проверяет дополнительное условие.
- Операторы сравнения: `==`, `!=`, `>`, `<`, `>=`, `<=`.
- После условия всегда ставится `:`.
- Код внутри условия пишется с отступом.
- `break` прерывает цикл досрочно.
