# Банк коротких задач на повторение

Используй один или два пункта за раз: они дополняют основную карточку и не должны превращаться в ещё одно большое ДЗ. Попроси ученика сначала ответить без запуска, затем проверить код или решить маленький вариант с нуля. Обновляй данные в повторных версиях.

| ID | Что проверить | Короткий вопрос / задание | Когда возвращать |
|---|---|---|---|
| R-01 | `input`, `int`, `float`, `print` | Что будет типом `input()`? В каком месте нужно преобразование, если ответ — цена 12.5? | +3, +6 уроков; проекты |
| R-02 | переменная и переназначение | Две переменные указывают на одно число. После `a = a + 1` изменилось исходное число или только связь имени? Объясни на выводе. | после переменных; снова после списков |
| R-03 | `/`, `//`, `%`, `**`, формат числа | Для 17 и 5 предскажи частное, целую часть и остаток. Округли показанную цену до двух знаков, сохранив расчётную точность. | +3; перед задачами с оплатой |
| R-04 | `if`, границы, `and`/`or` | Для диапазона «от 10 до 20 включительно» проверь 9, 10, 20, 21. Составь условие и объясни две границы. | +3, +6; контрольная по условиям |
| R-05 | `range`, шаг и счётчик | Сколько раз выполнится `range(2, 11, 3)` и какие значения получит переменная? Измени границу, чтобы включить 11. | после первого `for`; перед проектом |
| R-06 | аккумулятор и сброс состояния | Найди ошибку: сумма объявлена внутри цикла. На каком шаге результат теряет предыдущие значения? | +3, +6; после накопительных задач |
| R-07 | `while`, `break`, `continue` | Для цикла ввода команд объясни, что гарантирует завершение. Чем отличается пропуск текущего шага от выхода из цикла? | после `while`; в игре с попытками |
| R-08 | индексы, срез, `len` | Для строки из трёх символов предскажи `s[0]`, `s[-1]`, `s[:2]`. Что произойдёт при недопустимом индексе? | после строк и списков |
| R-09 | `append`, `extend`, `copy`, общие ссылки | Предскажи результат после `b = a; b.append(4)`. Затем повтори с копией списка. Какую операцию выберешь, если нужен независимый список? | +3 после списков; перед ООП |
| R-10 | возвращаемое значение метода | Почему результат `items.append(x)` не нужно присваивать обратно в `items`? Что возвращает метод? | после списков; через 6 занятий |
| R-11 | `.strip()`, `.lower()`, `.split()`, `.join()` | Очисти края строки, приведи слова к нижнему регистру, разбей по пробелам и собери их через запятую. Какой шаг меняет список слов? | после строк; в домашнем проекте |
| R-12 | `find`, индексы 0 и −1 | Что означают результаты `find()` равные 0 и −1? Составь проверку «нашёл/не нашёл», которая не перепутает их с False. | после строк; через 6 занятий |
| R-13 | словарь, `in`, `get`, `items` | Подсчитай частоты трёх слов. Как вернуть 0 для слова, которого ещё нет? Как пройти по парам ключ/значение? | после словарей; перед проектом |
| R-14 | `None` и пустая коллекция | Сравни отсутствие списка (`None`) и существующий, но пустой список. Почему `if values` не различает эти случаи? | после словарей; после функций |
| R-15 | параметр, аргумент, `print` и `return` | Может ли другая функция использовать текст, напечатанный `print`? Перепиши вычисление так, чтобы вызывающая функция получила результат. | +3 после функций; контрольная |
| R-16 | область видимости, изменение/переназначение | Функция получает список, делает `append`, затем внутри связывает параметр с новым списком. Какие изменения видны снаружи? | после аргументов и изменяемых объектов |
| R-17 | значения по умолчанию | Почему список в аргументе по умолчанию может сохраняться между вызовами? Покажи повторный вызов и безопасное исправление. | после урока аргументов; через 6 занятий |
| R-18 | `==` и `is`, атрибуты экземпляра | Сравни два разных пустых списка через `==` и `is`. Что означает каждый результат? Как доказать, что атрибуты двух объектов независимы? | после списков и ООП |
| R-19 | `try/except ValueError` | Какая именно строка может вызвать `ValueError`? Что в цикле нужно изменить после неудачного преобразования, чтобы не повторять ошибку бесконечно? | после исключений; при вводе проекта |
| R-20 | файл, `with`, кодировка и путь | В какой папке появится относительный файл? Почему `with` полезен? Как прочитать файл повторно после чтения до конца? | после файлов; при проекте с сохранением |
| R-21 | тест и граница | Для функции скидки добавь случай нулевой цены и скидки 100%. Что именно проверяет expected value? | +3 после тестов; перед защитой проекта |

## Правило выбора

- Если ученик выполнил карточку сам и объяснил шаги, назначь одну задачу на перенос нового контекста через 3 занятия.
- Если открыл подсказку, на ближайшем занятии попроси короткий вариант без подсказки, затем верни навык через 6 занятий.
- Если не смог объяснить или повторил ту же ошибку, зафиксируй статус «Повторить» и выбери более простой вопрос по той же конструкции.
- В одном ДЗ сочетай максимум один новый навык и один старый, если идёт обычная практика; проектная работа может объединить несколько уже изученных навыков.
