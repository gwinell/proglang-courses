# Реестр навыков и отложенное повторение

Используй реестр вместе с [маршрутом ДЗ](README.md). После проверки встроенного задания отметь текущий статус ученика по каждому основному и повторяемому навыку.

## Статусы

- **Самостоятельно:** применяет навык в новой задаче и объясняет решение.
- **С подсказкой:** завершил после подсказки или по образцу; навык пока не считается самостоятельным.
- **Повторить:** забыл применение, не объясняет выбор или допустил ту же ошибку повторно.

Успешный запуск скопированного кода сам по себе не подтверждает самостоятельное освоение.

## Планирование повторов

После каждого занятия выпиши новые и повторяемые ID/навыки. Для каждого ученика поставь ориентировочные отметки `+3 урока` и `+6 уроков`. Если занятие отменено, двигай календарные метки, сохраняя расстояние в пройденных темах.

Короткий повтор может быть одним из форматов:

1. Предсказать вывод 4–8 строк кода.
2. Найти и исправить одну конкретную ошибку.
3. Написать функцию/фрагмент с нуля по короткому требованию.
4. Объяснить выбор конструкции и назвать один граничный случай.

На проектном блоке оставь минимум одно раннее повторение в критериях приёмки проекта. Ученик должен применить прежнюю конструкцию без подсказки.

## Регистрация результата

| Дата/урок | Навык | Задача или вопрос | Статус | Следующая дата | Что повторить после ошибки |
|---|---|---|---|---|---|
|  |  |  | Самостоятельно / с подсказкой / повторить |  |  |

Не нужно ставить оценку за каждый короткий повтор. Цель реестра — выбрать следующую полезную практику, а не увеличить объём ДЗ.
