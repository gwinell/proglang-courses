# Домашние задания по Python

Здесь собраны основные домашние задания курса в едином формате. Каждая карточка объясняет сюжет, точное требование, ввод, ограничения, вывод, примеры и подсказки. Решение и готовый алгоритм в условии не публикуются.

## Как пользоваться карточками

1. Сначала прочитай сюжет и своими словами сформулируй, что нужно получить.
2. Отметь в условии входные данные, ограничения и точный формат вывода.
3. До написания кода выпиши 2–3 маленькие проверки, включая границу.
4. Попробуй решить задачу самостоятельно. Если застрял, открой только первую подсказку; ко второй переходи после новой попытки.
5. После решения объясни, где хранятся данные и почему программа верна.
6. Запусти все примеры из карточки, а затем придумай один свой тест.

Задания Codeforces — это оригинальные задачи или явно отмеченные адаптации с ссылкой на первоисточник. Адаптированная версия может использовать другой сюжет или русскую формулировку; если изменён ввод или вывод, её нельзя отправить в оригинальный Codeforces judge без обратной адаптации. Авторские задания курса явно помечены.

## Повторение

Интервалы ниже — рабочая учебная схема для планирования, а не универсальная гарантия запоминания. Преподаватель сдвигает повторение раньше, если ученик не смог применить навык самостоятельно. Короткие варианты формулировок собраны в [банке задач на повторение](review_tasks.md).

- **Сразу после урока:** основная карточка и короткое объяснение решения своими словами.
- **Через 3 следующих занятия:** 1 короткий вопрос на чтение/исправление похожего кода без подсказки.
- **Через 6 следующих занятий:** новая задача с тем же старым приёмом в другом сюжете.
- **При завершении крупного блока:** один смешанный набор навыков; во время проекта один ранний приём применяется в новой части программы.
- **После ошибки или подсказки:** повторная попытка на ближайшем занятии, а затем повтор в следующем интервале.

Не выдавай повторный вариант как дословную копию старой карточки. Меняй данные и контекст, сохраняя проверяемую идею. В карточках смотри поле «Повторить», а последовательность занятий веди по [реестру навыков](review_schedule.md).

## Сколько задавать

Обычно назначай основную карточку и до четырёх коротких пунктов практики (чтение, перенос, повторение, исправление ошибки). Когда начинается самостоятельный проект, уменьшай количество отдельных упражнений; проект заменяет часть обычного ДЗ, а не добавляется поверх максимальной нагрузки.
