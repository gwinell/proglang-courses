# Заметки преподавателя к домашним заданиям

**Материал преподавателя.** Этот файл находится в публичном репозитории и не является защищённым ключом ответов. Он содержит краткие ориентиры правильного решения, допустимые варианты и тестовые акценты; перед самостоятельной работой ученик должен открыть только карточку задания.

Проверяйте сформулированное требование, а не конкретный стиль кода. Если ученик выбрал другой корректный способ с уже изученными инструментами, принимайте его. Полные копируемые решения не нужны для проверки карточек: попросите ученика запустить программу, объяснить шаги и внести небольшое изменение.

| ID | Ориентир правильного решения | Допустимые варианты и важная проверка |
|---|---|---|
| HW-01 | Прочитать две строки в разные переменные и подставить значения в точную фразу. | Подстановка через f-строку или конкатенацию, если обе конструкции уже объяснены. Сравнить пунктуацию и пробелы. |
| HW-02 | Вес должен быть чётным, а каждый из двух кусков — положительным; для целочисленного веса подходят чётные значения от 4. | Корректно объединить условия через `and` или вложенную проверку. Проверить 2 и 4, а также нечётный вес. Codeforces 4A. |
| HW-03 | Полное число контейнеров — целая часть деления `n` на `k`, остаток — остаток от деления. | Ровно делящийся, нулевой и неполный контейнеры проверить отдельно. |
| HW-04 | Суммировать цены от `k` до `w*k`, затем вывести положительную разницу с деньгами или ноль. | Допустимы цикл с накопителем или формула, если формула уже пройдена. В карточке ввода намеренно три строки; у оригинала Codeforces 546A три числа находятся в одной строке. |
| HW-05 | Прочитать ровно `n` значений и увеличить счётчик, если значение между 10 и 20 включительно. | Можно использовать `and` или эквивалентные вложенные сравнения. Проверить 9, 10, 20 и 21; при `n=0` ответ равен 0. |
| HW-06 | Перебрать исходные массы и добавлять в новый список только значения строго меньше 5; вывести длину и список. | Пустой список печатает 0 и пустую строку. Не принимать удаление из того же списка во время перебора как надёжное решение. |
| HW-07 | Если строка непуста, сформировать заглавный первый символ и неизменённый остаток строки. | Срез и конкатенация или другой разобранный способ. Не принимать `.capitalize()`, если он меняет регистр оставшихся символов. Codeforces 281A. |
| HW-08 | Для каждого слова длиной строго больше 10 собрать первый символ, количество внутренних символов и последний символ; остальные слова сохранить. | Корректны цикл по словам и аккуратная индексация. Граница длиной 10 остаётся без изменений. Codeforces 71A. |
| HW-09 | Нормализовать регистр, разбить строку, вести словарь частот и отдельный список порядка первого появления. | Можно использовать `get()` или явную проверку ключа. Пустой текст даёт пустой вывод; дубли увеличивают счётчик, но не повторяют слово в порядке. |
| HW-10 | Посчитать стоимость с минимумом 300 рублей, затем уменьшить её на 20% для участника клуба и вернуть число. | Важно применить скидку после минимальной базовой стоимости, как сказано в условии; тестировать 0/2/3/5 км и оба значения `member`. |
| HW-11 | `score` каждого ученика хранится в атрибуте экземпляра; метод изменяет только `self.score` данного объекта. | Формат вывода можно организовать через две печати или отдельное форматирование строки. После начисления у второго ученика остаётся исходный балл. |
| HW-12 | Повторять чтение, преобразовывать через `int`, перехватывать только `ValueError`; после успешного преобразования выйти из цикла и подтвердить число. | Для выхода подходят `break` или условие цикла. Проверить ошибочный ввод, сразу правильный ввод и ошибку перед успехом. |
| HW-13 | Записать три названия с переводом строки в UTF-8 файл, затем открыть его для чтения и вывести нумерованные строки. | Нумерация через явный счётчик или `enumerate`, если он изучен. Не удалять значащие пробелы в названиях; тестировать запуск из ожидаемой рабочей папки. |
| HW-14 | Функция возвращает цену после указанной скидки; тесты независимо сравнивают результат с ожидаемым для 0%, 50% и 100%. | Можно использовать `unittest` или согласованный в курсе способ тестирования. Добавить нулевую цену и объяснить каждый ожидаемый результат. |
| HW-15 | Счётчик места начинается с 1 вне обоих циклов и растёт для каждого места; внутренний цикл печатает `c` чисел, после него печатается перевод строки. | Допускается форматирование через промежуточную строку, если эта техника уже изучена; число мест всё равно формируется вложенными циклами. Проверить форму 1×1, несколько рядов по одному месту и сетку 2×3. |

## Как оценивать без привязки к коду

Для каждой карточки используйте её рубрику и тестовые случаи из таблицы «Для преподавателя». Обычно ученик должен показать обычный пример, границу и случай без элементов или совпадений, если он допустим условием. При расхождении сначала уточните, правильно ли ученик прочитал ввод и формат результата; затем локализуйте план, состояние программы или конкретную строку.

Ученику, который решил верно с подсказкой, назначьте один короткий перенос из [банка повторения](review_tasks.md), а не ещё одну полную карточку. После ошибки проверьте связанную предпосылку из [реестра навыков](review_schedule.md).
