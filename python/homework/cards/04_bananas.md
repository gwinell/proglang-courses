# ДЗ-04. Бананы для солдата

**Статус:** адаптация задачи Codeforces 546A · **Обязательная** · ID `HW-04`

## Сюжет
Солдат покупает `w` бананов. Первый стоит `k` монет, второй — `2k`, третий — `3k` и так далее. У него есть `n` монет.

## Задача
Определите, сколько монет ему нужно занять. Если денег хватает, выведите `0`.

## Входные данные
Три строки: цена первого банана `k`, имеющиеся деньги `n`, желаемое количество бананов `w` — по одному числу в строке.

## Ограничения
`1 ≤ k,w ≤ 1000`, `0 ≤ n ≤ 10^9`.

## Выходные данные
Одно целое число — недостающая сумма, не меньше нуля.

## Примеры
`3`, затем `17`, затем `4` → `13`. Бананы стоят 3, 6, 9 и 12, всего 30; не хватает 13.

`2`, затем `20`, затем `3` → `0`. Стоимость 12, имеющихся денег достаточно.

## Подсказки
1. Сначала найдите полную стоимость всех бананов, прибавляя цену очередного к общей сумме.
2. После цикла сравните стоимость с имеющимися деньгами; ответ не должен быть отрицательным.

## Что сдать
`hw04.py`, два приведённых запуска и короткое объяснение, что хранит переменная накопленной суммы.

Эта версия не подходит для прямой отправки в оригинальный проверяющий сервис без изменения чтения ввода. Код и полный текст оригинала не копируются.

## Для преподавателя
**Основной навык:** `for`, `range`, накопитель. **Повторить:** ввод нескольких чисел, арифметика, условие. **Предпосылки:** `for` и числа. **Тесты:** пример, стоимость равна наличным, денег с запасом. **Типичные ошибки:** диапазон включает лишний номер; сумма сбрасывается в цикле; цена на каждой итерации не меняется. **Оценивание:** цикл суммирования — 2; корректный дефицит — 1; пояснение накопителя — 1. **Следующий шаг:** счётчик и цикл по коллекции.
