# ДЗ-02. Делим арбуз

**Статус:** адаптация оригинальной задачи Codeforces 4A · **Обязательная** · ID `HW-02`

## Сюжет
Петя и Билли делят арбуз между собой. Каждый хочет получить кусок положительного веса, который выражается чётным числом килограммов.

## Задача
По общей массе арбуза определите, можно ли разделить его на две положительные целые чётные части. Выведите `YES`, если можно, иначе `NO`.

## Входные данные
Одна строка: целое число `w` — масса арбуза.

## Ограничения
`1 ≤ w ≤ 100`; вес частей должен быть положительным целым числом.

## Выходные данные
Одна строка: `YES` или `NO` заглавными латинскими буквами.

## Примеры
Ввод `8` → вывод `YES`. Пояснение: подходят части 2 и 6.

Ввод `2` → вывод `NO`. Пояснение: разрезать на две положительные чётные целые части нельзя.

Ввод `3` → вывод `NO`. Пояснение: сумма двух чётных чисел всегда чётная.

## Подсказки
1. Сначала проверьте, чётна ли общая масса. Этого условия ещё недостаточно.
2. Подумайте о наименьшей допустимой массе каждого куска.

## Что сдать
`hw02.py`; приложите результаты для `w=8`, `w=2`, `w=3`.

## Источник и адаптация
Пересказ задачи [Codeforces 4A — Watermelon](https://codeforces.com/problemset/problem/4/A). Сохранены математическое требование и ограничения; сюжет изложен по-русски, примеры расширены граничным случаем. Формат результата соответствует оригиналу.

## Для преподавателя
**Основной навык:** `if/else`, сравнение, `%`. **Повторить:** `int(input())`, `print`. **Предпосылки:** числа и условия. **Тесты:** 1, 2, 3, 4, 100. **Типичные ошибки:** считать, что любой чётный вес подходит; забыть, что обе части положительны. **Оценивание:** верный критерий — 2; границы проверены — 1; точный вывод — 1. **Следующий шаг:** циклы с условием.
