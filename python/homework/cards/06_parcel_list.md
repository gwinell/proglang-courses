# ДЗ-06. Посылки для робота

**Статус:** авторская задача курса · **Обязательная** · ID `HW-06`

## Сюжет
Робот-курьер получил список масс посылок. На подъёмник можно отправить только посылки легче 5 кг; остальные надо оставить на складе.

## Задача
Прочитайте список масс. Создайте новый список только из масс меньше 5 и выведите его длину и сами значения в исходном порядке.

## Входные данные
Первая строка — `n`. Вторая строка содержит `n` целых чисел через пробел. Если `n=0`, второй строки может не быть.

## Ограничения
`0 ≤ n ≤ 1000`, `0 ≤ масса ≤ 100`.

## Выходные данные
Первая строка — количество подходящих посылок. Вторая — их массы через пробел; если список пуст, выведите пустую строку.

## Примеры
Ввод:
```text
5
2 5 1 8 4
```
Вывод:
```text
3
2 1 4
```
Пояснение: масса ровно 5 уже не меньше 5, поэтому она не попадает в результат.

Ввод `0` → вывод: строка `0`, затем пустая строка.

## Подсказки
1. Пройдите по исходному списку и проверяйте каждую массу отдельно.
2. Для подходящих значений используйте новый список и `append()`. Не удаляйте элементы из списка во время обхода.

## Что сдать
`hw06.py`, пример и отдельный запуск с пустым списком.

## Для преподавателя
**Основной навык:** цикл по списку, условие, `append`, `len`. **Повторить:** индексы/элементы, счётчик, форматирование. **Предпосылки:** списки и `for`. **Типичные ошибки:** изменяют исходный список при обходе; включают 5; теряют исходный порядок. **Оценивание:** фильтрация — 2; пустой случай — 1; порядок/вывод — 1. **Следующий шаг:** обработка строки как коллекции символов.
