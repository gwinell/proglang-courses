# ДЗ-15. Схема мест в зале

**Статус:** авторская задача курса · **Обязательная** · ID `HW-15`

## Сюжет

Организатор концерта размечает небольшой зал. В каждом ряду места нумеруются слева направо, а следующий ряд продолжается со следующего номера.

## Задача

По количеству рядов `r` и мест в каждом ряду `c` выведите схему нумерации. В каждой строке вывода должны находиться номера мест одного ряда через пробел. Используйте два вложенных цикла: внешний выбирает ряд, внутренний последовательно печатает места этого ряда.

## Входные данные

Две строки: в первой количество рядов `r`, во второй количество мест в каждом ряду `c`.

## Ограничения

`1 ≤ r ≤ 8`, `1 ≤ c ≤ 9`. Ввод всегда корректный.

## Выходные данные

Выведите `r` строк по `c` целых чисел. Нумерация начинается с 1 и идёт непрерывно по строкам. В конце каждой строки, кроме последней, должен быть перевод строки; лишние знаки после последнего числа не нужны.

## Примеры

Ввод:

```text
2
3
```

Вывод:

```text
1 2 3
4 5 6
```

Сначала напечатаны три места первого ряда, затем ещё три места второго ряда.

Ввод `1` и `1` → вывод `1`. В зале ровно одно место.

Ввод `3` и `1` → вывод из трёх строк: `1`, `2`, `3`. В каждом ряду одно место.

## Подсказки

1. До цикла создай номер следующего места и начни его с 1. После каждого выведенного места увеличивай номер на 1.
2. Для каждого ряда внутренний цикл должен повториться `c` раз. После него выведи перевод строки; не увеличивай номер места в начале нового ряда.

## Что сдать

Файл `hw15.py`, результаты трёх примеров и короткую таблицу первых шести значений: номер ряда, номер места в ряду, выведенный номер.
