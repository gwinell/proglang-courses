# ДЗ-09. Частотный словарь станции

**Статус:** авторская задача курса · **Обязательная** · ID `HW-09`

## Сюжет
На станции записали названия встречавшихся сигналов. Аналитик хочет знать, сколько раз пришёл каждый тип сигнала.

## Задача
Прочитайте строку слов, разделённых пробелами. Без учёта регистра посчитайте частоту каждого слова и выведите пары «слово количество» в порядке первого появления. Для порядка храните отдельный список новых слов.

## Входные данные
Одна строка; слова состоят из английских букв и разделяются одним или несколькими пробелами. Строка может быть пустой.

## Ограничения
Не более 1000 слов; длина слова от 1 до 30 символов.

## Выходные данные
Для каждого различного слова — строка `слово количество`, всё в порядке первого появления. Для пустой строки ничего не выводите.

## Примеры
`Radar lidar RADAR` → строки `radar 2`, `lidar 1`. Регистр приводится к нижнему до подсчёта.

Пустая строка → пустой вывод. Нет слов — нечего учитывать.

## Подсказки
1. Приведите слова к нижнему регистру и получите список через `split()`.
2. В словаре ключ — слово, значение — число встреч. Когда слово встречается впервые, добавьте его в список порядка; затем увеличьте его счётчик в словаре. В конце пройдите по списку порядка и выведите пары.

## Что сдать
`hw09.py` и запуск с повторяющимся словом и пустой строкой.

## Для преподавателя
**Основной навык:** словарь, список порядка, `in`/`get`, цикл, `split`. **Повторить:** регистр, `append`, счётчик. **Предпосылки:** строки и словари. **Типичные ошибки:** ищут слово под разными регистрами; забывают начальное значение; используют неупорядоченный результат множества. **Оценивание:** частоты — 2; нормализация — 1; пустой ввод — 1. **Следующий шаг:** вынести подсчёт в функцию.
