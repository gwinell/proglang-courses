# ДЗ-14. Проверка скидки

**Статус:** авторская задача курса · **Обязательная** · ID `HW-14`

## Сюжет
Магазин применяет скидку к заказу. Перед запуском новой версии нужно убедиться, что расчёт верен для обычной цены и граничных случаев.

## Задача
Напишите функцию `final_price(price, discount)`, возвращающую целую цену после скидки в процентах. Затем добавьте автоматические тесты минимум для трёх ситуаций: скидка 0%, скидка 50%, скидка 100%.

## Входные данные
Для функции это аргументы; программа может не читать `input()`. `price` — целое число от 0 до 1 000 000, кратное 100; `discount` — целое от 0 до 100.

## Ограничения
Цена кратна 100 рублям, поэтому для целых процентов итог получается целым числом. Проверяются только значения из указанных диапазонов.

## Выходные данные
Функция возвращает итоговую цену в целых рублях. Тесты должны сообщать об ошибке при неверном результате.

## Примеры
`final_price(1000, 0)` → `1000`; исходная цена сохраняется.

`final_price(1000, 50)` → `500`.

`final_price(1000, 100)` → `0`.

## Подсказки
1. Сначала реализуйте и вручную проверьте функцию. Она должна вернуть значение, а не печатать его.
2. В тестах сравните вызов функции с ожидаемым числом. Добавьте ещё один тест с нулевой ценой.

## Что сдать
Модуль с функцией и тестами, запускаемыми выбранным в курсе способом. Укажите команду запуска и приложите успешный вывод тестов.

## Для преподавателя
**Основной навык:** маленькая функция и автоматические проверки. **Повторить:** аргументы/return, целочисленная арифметика, границы, независимые тестовые случаи. **Предпосылки:** модуль тестирования, уроки функций. **Типичные ошибки:** тест повторяет реализацию вместо требования; проверяется только один обычный случай; функция печатает `None`. **Оценивание:** функция — 1; три сценария — 2; команда запуска и интерпретация — 1. **Следующий шаг:** модульная структура проекта.
