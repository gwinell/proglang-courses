# ДЗ-05. Проверка перед запуском

**Статус:** авторская задача курса · **Обязательная** · ID `HW-05`

## Сюжет
Перед стартом ракеты диспетчер вводит показания датчиков. Нужно посчитать, сколько из них находятся в безопасном диапазоне.

## Задача
Сначала дано число `n`, затем `n` целых показаний. Посчитайте показания от 10 до 20 включительно.

## Входные данные
Первая строка — `n`. Следующие `n` строк — по одному целому числу.

## Ограничения
`0 ≤ n ≤ 1000`, `−1000 ≤ x ≤ 1000`. Ввод корректный.

## Выходные данные
Одно целое число — количество безопасных показаний. Если `n=0`, выведите 0.

## Примеры
Ввод `5`, затем `9, 10, 15, 20, 21` → вывод `3`. Значения 10, 15 и 20 входят в диапазон.

Ввод `0` → вывод `0`. Проверок не было.

## Подсказки
1. Повторите чтение ровно `n` раз. Для каждого значения задайте отдельный вопрос «попадает ли оно в диапазон?».
2. Используйте условие с двумя сравнениями и увеличивайте счётчик только при истинном условии.

## Что сдать
`hw05.py`, проверки для `n=0` и значений на обеих границах 10 и 20.

## Для преподавателя
**Основной навык:** цикл, составное условие, счётчик. **Повторить:** `int`, сравнения, `and`. **Предпосылки:** цикл и ветвление. **Типичные ошибки:** исключён верхний край; счётчик увеличивается без условия; цикл делает `n+1` чтений. **Оценивание:** точное число повторов — 1; границы — 2; пустой ввод набора — 1. **Следующий шаг:** собирать подходящие элементы в список.
