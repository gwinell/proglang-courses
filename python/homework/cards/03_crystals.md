# ДЗ-03. Кристаллы для экспедиции

**Статус:** авторская задача курса · **Обязательная** · ID `HW-03`

## Сюжет
Экспедиция собрала кристаллы для лаборатории. В один контейнер помещается ровно `k` кристаллов; сначала заполняют контейнеры полностью, а остаток упаковывают отдельно.

## Задача
По числу кристаллов `n` и вместимости контейнера `k` найдите число полных контейнеров и число оставшихся кристаллов.

## Входные данные
Две строки: в первой целое `n`, во второй целое `k`.

## Ограничения
`0 ≤ n ≤ 10000`, `1 ≤ k ≤ 100`.

## Выходные данные
Два целых числа через пробел: полные контейнеры, затем остаток.

## Примеры
`17` и `5` → `3 2`. Три контейнера заполнены, ещё два кристалла остались.

`20` и `5` → `4 0`. Остатка нет.

`0` и `5` → `0 0`. Кристаллов нет.

## Подсказки
1. Разделите задачу на две величины: сколько раз вместимость целиком помещается в запас и что остаётся.
2. Для этого пригодятся `//` и `%`; они связаны с делением нацело и остатком.

## Что сдать
`hw03.py` и вывод программы для каждого примера.

## Для преподавателя
**Основной навык:** `//`, `%`. **Повторить:** ввод, целые числа, форматирование вывода. **Предпосылки:** арифметика. **Тесты:** ноль, точное деление, ненулевой остаток. **Типичные ошибки:** поменять местами частное и остаток; не проверить `n=0`. **Оценивание:** обе величины — 2; формат — 1; объяснение крайних примеров — 1. **Следующий шаг:** использовать остаток в условии.
