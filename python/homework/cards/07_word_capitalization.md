# ДЗ-07. Заглавная буква

**Статус:** оригинальная задача Codeforces 281A · **Обязательная** · ID `HW-07`

## Сюжет
Сервис заметок приводит заголовок к единому стилю: первая буква слова должна стать заглавной, остальные символы остаются как были.

## Задача
Прочитайте одно слово и выведите его, заменив только первую букву на заглавную.

## Входные данные
Одна непустая строка без пробелов. Слово состоит из английских букв.

## Ограничения
Длина слова от 1 до 1000 символов; регистр остальных букв менять нельзя.

## Выходные данные
Одно слово после преобразования.

## Примеры
`konjac` → `Konjac`. Первая буква меняется, остальные сохраняются.

`ApPLe` → `ApPLe`. Первая уже заглавная; остальные остаются без изменений.

## Подсказки
1. Разделите строку на первый символ и оставшуюся часть.
2. Преобразуйте через `.upper()` только первый символ, затем соберите строку обратно.

## Что сдать
`hw07.py` и оба запуска.

## Источник
[Codeforces 281A — Word Capitalization](https://codeforces.com/problemset/problem/281/A). Сюжет пересказан; требования об изменении только первой буквы и латинском алфавите сохранены.

## Для преподавателя
**Основной навык:** индексирование строки и методы регистра. **Повторить:** ввод строки, конкатенация, срезы (если уже изучены; решение не обязано использовать срез). **Предпосылки:** строки. **Типичные ошибки:** `.capitalize()` меняет регистр остальных букв; исходная строка не изменяется на месте. **Оценивание:** первая буква — 2; остальные сохранены — 1; односимвольная строка — 1. **Следующий шаг:** цикл по нескольким словам.
