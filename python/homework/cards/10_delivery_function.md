# ДЗ-10. Стоимость доставки

**Статус:** авторская задача курса · **Обязательная** · ID `HW-10`

## Сюжет
Интернет-магазин доставляет заказ. Стоимость зависит от расстояния; участники клуба получают скидку.

## Задача
Напишите функцию `delivery_cost(distance, member)`, которая возвращает стоимость: 100 рублей за каждый километр, но не меньше 300 рублей. Если `member` равен `True`, после расчёта применяется скидка 20%. Функция не печатает результат.

## Входные данные
Две строки: неотрицательное целое расстояние `distance`, затем `1` для участника клуба и `0` для остальных. Передайте в функцию `True`, если введено `1`, и `False`, если введено `0`; напечатайте результат.

## Ограничения
`0 ≤ distance ≤ 1000`. Скидка даёт целое число рублей для заданной формулы (20% от суммы, кратной 100).

## Выходные данные
Одно целое число — стоимость в рублях.

## Примеры
`2`, затем `0` → `300`. Расчёт 200 рублей повышается до минимальной стоимости.

`5`, затем `1` → `400`. База 500 рублей, скидка 100.

## Подсказки
1. Разбейте расчёт на базовую цену и проверку скидки.
2. В функции используйте `return`; проверьте случай ниже минимума и случай ровно на границе 3 км.

## Что сдать
`hw10.py`; отдельно покажите вызовы `delivery_cost(2, False)` и `delivery_cost(5, True)` и убедитесь, что повторный вызов не зависит от предыдущего.

## Для преподавателя
**Основной навык:** параметры, условие, `return`, повторный вызов. **Повторить:** арифметика, сравнение, логическое значение. **Предпосылки:** функции. **Типичные ошибки:** печать вместо возврата; скидка до применения минимума; случайный общий изменяемый параметр. **Оценивание:** минимум — 1; скидка — 1; возвращаемое значение — 1; граничная проверка — 1. **Следующий шаг:** методы и состояние экземпляра.
