# ДЗ-12. Надёжный ввод показаний

**Статус:** авторская задача курса · **Обязательная** · ID `HW-12`

## Сюжет
Оператор вводит номер отсека. Пока введённая строка не является целым числом, программа просит попробовать снова.

## Задача
Читайте строку, пока она не преобразуется в целое число. После успешного ввода выведите `Отсек N принят`, где `N` — число. Обработайте только `ValueError` преобразования.

## Входные данные
Несколько строк. Неподходящие строки могут содержать любой текст. Первая строка, которую `int()` может преобразовать, находится не позднее 10-й строки и содержит число от 1 до 99.

## Ограничения
Первая корректная строка гарантированно встретится не позднее 10-й попытки. Ввод заканчивается только после неё.

## Выходные данные
При каждой ошибке выводите `Повторите ввод`. После успешного ввода выведите подтверждение в указанном формате.

## Примеры
Ввод `восемь`, затем `8` → вывод `Повторите ввод`, `Отсек 8 принят`.

Ввод `12` → вывод `Отсек 12 принят`.

## Подсказки
1. Повторяйте чтение, пока не сможете сохранить корректное целое число.
2. Поместите `int()` в `try`; перехватите `ValueError`. Успешный случай должен завершить повторение.

## Что сдать
`hw12.py` и запуски для первого корректного ввода и для ошибки с последующим исправлением.

## Для преподавателя
**Основной навык:** `try/except ValueError`, цикл повторения, преобразование типа. **Повторить:** `input`, `while`, условие завершения, `print`. **Предпосылки:** циклы и исключения. **Типичные ошибки:** бесконечный цикл после успеха; перехват всех исключений; переменная результата не задана при неудаче. **Оценивание:** повтор до успеха — 2; только `ValueError` — 1; сообщения и финальный результат — 1. **Следующий шаг:** проект с данными и тестами.
