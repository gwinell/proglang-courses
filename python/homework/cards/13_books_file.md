# ДЗ-13. Каталог книг в файле

**Статус:** авторская задача курса · **Обязательная** · ID `HW-13`

## Сюжет
Библиотекарь хранит короткий список книг в обычном текстовом файле, чтобы данные остались после закрытия программы.

## Задача
Запишите три названия книг — по одному на строку — в `books.txt`. Затем откройте этот файл и выведите все строки с номерами от 1 до 3.

## Входные данные
Ввод не нужен: используйте заданные в коде названия `Дюна`, `Хоббит`, `Солярис`.

## Ограничения
Не подключайте внешние библиотеки. Открывайте файл с `encoding="utf-8"` внутри `with`.

## Выходные данные
Три строки: `1. Дюна`, `2. Хоббит`, `3. Солярис`.

## Пример и пояснение
После запуска из папки проекта рядом со скриптом появляется файл `books.txt` с тремя строками. Программа перечитывает его, нумерует строки и выводит ожидаемый список.

## Подсказки
1. Сначала откройте файл для записи и запишите каждую книгу вместе с символом перевода строки `\n`.
2. Закройте блок `with`, затем откройте файл для чтения и используйте цикл по строкам. Удалите перевод строки с конца, не обрезая пробелы внутри названия.

## Что сдать
`hw13.py`, `books.txt` после запуска и копию вывода.

## Для преподавателя
**Основной навык:** `with open`, режимы `w`/`r`, кодировка, чтение строк. **Повторить:** списки/цикл, `enumerate` при наличии в курсе, форматирование. **Предпосылки:** файлы. **Типичные ошибки:** перезапись файла на этапе чтения; забыли перевод строки; не указали кодировку; запускают из неожиданной рабочей папки. **Оценивание:** запись и чтение — 2; UTF-8/with — 1; точный вывод — 1. **Следующий шаг:** отделить функции и написать тест.
