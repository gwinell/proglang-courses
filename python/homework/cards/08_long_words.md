# ДЗ-08. Короткие подписи

**Статус:** оригинальная задача Codeforces 71A · **Обязательная** · ID `HW-08`

## Сюжет
В карточках каталога слишком длинные слова занимают много места. Сервис сокращает только слова длиннее заданного порога.

## Задача
Для каждого слова длиной больше 10 символов выведите первую букву, число букв между первой и последней, затем последнюю букву. Более короткие слова выведите без изменений.

## Входные данные
Первая строка — количество слов `n`. Далее `n` строк, по одному слову.

## Ограничения
`1 ≤ n ≤ 100`; длина каждого слова от 1 до 100; только строчные латинские буквы. Порог строго больше 10.

## Выходные данные
Для каждого входного слова — одна строка результата в том же порядке.

## Примеры
Ввод:
```text
4
word
localization
internationalization
cat
```
Вывод:
```text
word
l10n
i18n
cat
```
Пояснение: `localization` имеет 10 букв между первой и последней, а слово длиной ровно 10 не сокращалось бы.

## Подсказки
1. Используйте цикл, чтобы обработать слова по одному. Сначала сравните длину с 10.
2. Для длинного слова результат составляется из первого символа, числа `len(word) - 2` и последнего символа.

## Что сдать
`hw08.py`, проверку слова длиной 10 и слова длиной 11.

## Источник
[Codeforces 71A — Way Too Long Words](https://codeforces.com/problemset/problem/71/A). Оригинальный ввод, правило порога и результат сохранены; в примере добавлено короткое слово `cat`.

## Для преподавателя
**Основной навык:** цикл по числу записей, длина строки, индексы. **Повторить:** `input`, ветвление, `str`/`int`. **Предпосылки:** цикл и строки. **Типичные ошибки:** условие `>=10`; количество букв в середине считают как `len-1`; выводят ответ в одной строке. **Оценивание:** порог — 1; сокращение — 2; порядок строк — 1. **Следующий шаг:** подсчёты в словаре.
