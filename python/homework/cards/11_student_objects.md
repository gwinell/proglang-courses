# ДЗ-11. Электронные карточки учеников

**Статус:** авторская задача курса · **Обязательная** · ID `HW-11`

## Сюжет
В учебном приложении у каждого ученика есть личная карточка с именем и баллами. Изменение одной карточки не должно менять остальные.

## Задача
Создайте класс `Student` с `name`, `score` и методом `add_points(amount)`. Метод увеличивает балл только текущего ученика. Создайте двух учеников, измените балл первого и выведите обе карточки.

## Входные данные
Для этой задачи вход не нужен: создайте объекты в коде с именами «Аня» и «Миша» и начальными баллами 10 и 7. Начислите Ане 3 балла.

## Ограничения
`amount` — положительное целое число. Используйте только знакомые классы, `__init__`, `self` и методы.

## Выходные данные
Две строки вида `Имя: балл`, по одной на ученика. Ожидается `Аня: 13`, затем `Миша: 7`.

## Примеры и пояснение
До вызова значения равны 10 и 7. После `anya.add_points(3)` баллы равны 13 и 7: метод меняет атрибут объекта `anya`.

## Подсказки
1. `score` должен быть атрибутом экземпляра, создаваемым через `self.score = score`.
2. В методе прибавьте `amount` к `self.score`; не создавайте общий атрибут `Student.score`.

## Что сдать
`hw11.py` и короткое объяснение, почему второй объект остался без изменений.

## Для преподавателя
**Основной навык:** экземпляры, атрибуты, `self`, изменение состояния методом. **Повторить:** параметры, `return`/`print`, независимое состояние. **Предпосылки:** функции и основы ООП. **Типичные ошибки:** забыли `self`; атрибут класса вместо атрибута экземпляра; метод только печатает вместо изменения. **Оценивание:** конструктор — 1; метод — 1; два независимых результата — 1; объяснение — 1. **Следующий шаг:** сохранять данные между запусками.
