# Завершённая консольная программа: аргументы, ошибки и Git

Материал проходит после уроков о функциях, файлах и модуле `__main__`. Примеры требуют Python 3.10+ и стандартной библиотеки.

## Результаты

Ученик запускает файл из терминала, передаёт параметры, получает понятную ошибку при ожидаемой проблеме с данными и сохраняет рабочие изменения в отдельном Git-репозитории.

## 1. Запуск файла и рабочая папка

Открой терминал в папке проекта и выполни:

```text
python word_count.py sample.txt
```

Путь `sample.txt` считается от **текущей рабочей папки** — папки, в которой открыт терминал, — а не автоматически от папки файла программы. Проверь её командой `pwd` в macOS/Linux или `cd` в Windows. Если Python запускается командой `python3`, используй её вместо `python`.

В этой папке лежат [пример программы](examples/word_count.py) и [исходный текст](examples/sample.txt). Например:

```text
python examples/word_count.py examples/sample.txt
```

Вызов с `--help` показывает справку, созданную `argparse`:

```text
python examples/word_count.py --help
```

## 2. Параметры командной строки

В программе есть обязательный позиционный аргумент `file` и необязательный именованный `--top`:

| Команда | Назначение |
|---|---|
| `python examples/word_count.py examples/sample.txt` | Прочитать файл и вывести число строк и слов |
| `python examples/word_count.py examples/sample.txt --top 3` | Также вывести до трёх самых частых слов |
| `python examples/word_count.py --help` | Показать формат запуска и описание параметров |

Параметры — внешний интерфейс программы. Пользователю не нужно менять исходный код, чтобы выбрать файл или число частых слов.


Кодировка файла задана как UTF-8. Если текст создан в другой кодировке или повреждён, возникнет `UnicodeDecodeError`; программа сообщает об этом явно. Не используй `errors="ignore"`: незаметное удаление байтов портит исходные данные.

`print` направляет обычный результат в stdout; сообщение `argparse` об ошибке — в stderr. Позже, когда понадобятся уровни сообщений и запись в файл, используй стандартный модуль `logging`. Для первых CLI-программ достаточно точных сообщений об ожидаемых ошибках.

Авторский материал курса. Командные параметры объясняются на встроенном модуле `argparse`; команды Git — минимальный учебный маршрут для сохранения истории.
