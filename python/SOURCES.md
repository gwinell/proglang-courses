## Уточнения по официальной документации Python

При адаптации проверены пограничные случаи, которые легко потерять в упрощённом объяснении:

- [Присваивание и поверхностная копия](https://docs.python.org/3/library/copy.html): копирование внешнего контейнера не создаёт независимые вложенные объекты.
- [Списки и коллекции](https://docs.python.org/3/tutorial/datastructures.html): изменяющие методы, `sort` и `sorted`, способы перебора.
- [Управление потоком и функции](https://docs.python.org/3/tutorial/controlflow.html): `range`, завершение циклов, значения по умолчанию.
- [Встроенные типы](https://docs.python.org/3/library/stdtypes.html): истинность 0 и -1, строковые методы, хешируемость и коллекции.
- [Встроенные функции](https://docs.python.org/3/library/functions.html): `iter`, `next`, `zip`, `any`, `all`.
- [Классы](https://docs.python.org/3/tutorial/classes.html): идентичность объектов, методы, атрибуты класса и экземпляра.
- [Ввод и вывод](https://docs.python.org/3/tutorial/inputoutput.html): позиции чтения, кодировки, `with` и форматы хранения.

Ссылки ведут к поддерживаемой документации Python 3. Новые примеры курса используют возможности Python 3.10+ и не требуют новых функций из более поздних версий.
