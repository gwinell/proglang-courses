# Практикумы: сначала план, потом код

Материал рассчитан на три короткие встречи после циклов, коллекций и функций соответственно. На каждой встрече ученик сначала разбирает задачу словами и вручную, а затем пишет код. Не используйте приём, который ещё не объяснён в курсе.

## Рабочий лист алгоритма

Для каждой задачи ответь на вопросы:

1. Что дано? Как выглядят входные данные?
2. Что нужно получить и в каком формате?
3. Какие значения разрешены? Что будет на границах?
4. Посчитай один маленький пример вручную.
5. Что повторяется? Какое действие выполняется для каждого элемента?
6. Какие значения нужно помнить: сумму, количество, лучший результат, ответ?
7. Запиши план обычными словами.
8. Переведи каждое действие в Python.
9. Проверь обычный пример, границу и случай без подходящих элементов.
10. Объясни, почему программа заканчивается и почему ответ верен.

## Чек-лист решения

- [ ] Могу объяснить вход и требуемый вывод.
- [ ] Проверил пример вручную до программирования.
- [ ] Назвал каждую переменную по её роли.
- [ ] Начальное значение каждой переменной обосновано.
- [ ] Сравнил результат на обычном и граничном примерах.
- [ ] Могу рассказать, как меняется состояние на каждом шаге.
