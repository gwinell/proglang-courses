# КуМир: алгоритмический язык и исполнитель Робот

Материалы курса для начинающих. Курс соединяет изучение школьного алгоритмического языка с практикой в среде КуМир. Исполнитель Робот используется как одна из проверяемых программами практических линий курса.

## Принцип курса

Каждое занятие заканчивается программой, которую ученик запускает в КуМире. Для неё заранее задаются входные данные и ожидаемый результат: текстовый вывод, конечные значения величин или состояние поля Робота. Где применимо, программа проверяется на нескольких наборах данных и граничных случаях.

Маршрут обучения: предсказать результат → запустить программу → сравнить с ожидаемым → изменить одну деталь → проверить снова → написать похожую программу самостоятельно.

| № | Тема | Проверочная программа и критерий |

## Как устроена проверка

Для каждой проверочной программы в материалах курса будут указаны:

1. начальная обстановка или входные данные;
2. ожидаемый вывод, значения величин или конечное состояние поля;
3. как минимум один дополнительный тест, который проверяет другой путь выполнения;
4. критерии, по которым ученик может сам найти ошибку.

Задачи для Робота должны явно указывать стены, стартовое положение и клетки, которые требуется закрасить. Для программ с вводом проверяются обычные значения, граничные значения и разные ветви условия. Неизученная обработка некорректного ввода не требуется.

## Пример интеграционной проверочной программы

Программа спрашивает число шагов, затем закрашивает столько клеток, двигаясь вправо. Начальная обстановка должна содержать свободный коридор необходимой длины.

```text
использовать Робот
алг Ряд
нач
  цел n, i
  вывод "Сколько клеток закрасить? "
  ввод n
  нц для i от 1 до n
    закрасить
    вправо
  кц
кон
```

Контрольный случай: при `n = 4` Робот закрашивает четыре клетки и перемещается на четыре клетки вправо. Дополнительные случаи: `n = 1` и `n = 6` на обстановках с достаточным свободным местом.

## Дополнительные темы

После основной линии курс можно расширить задачами на вспомогательные алгоритмы с параметрами, функции, массивы, обработку последовательностей и более сложные обстановки Робота. Каждая дополнительная конструкция также вводится через запускаемую программу с заданными тестами.
