# Домашняя работа к разделу 2. Величины, ввод, вывод и вычисления

Реши задачи отдельными программами КуМира. Для каждой приложи исходный файл `.kum` и запуски на примерах из условия. Величины описывай подходящим типом; не добавляй приглашения ко вводу, если требуется точный формат вывода.

## 1. Запасы экспедиции

Экспедиция собрала `n` кристаллов и раскладывает их в контейнеры вместимостью `k` кристаллов. В последнем контейнере может остаться неполное количество.

**Входные данные:** два целых числа `n` и `k` (`0 ≤ n ≤ 10 000`, `1 ≤ k ≤ 100`). Числа вводятся в одной строке через пробел.

**Выходные данные:** количество полностью заполненных контейнеров и количество кристаллов, оставшихся после их заполнения.

| Ввод | Вывод |
|---|---|
| `17 5` | `3 2` |
| `20 5` | `4 0` |
| `0 5` | `0 0` |

**Проверяется:** описание `цел`, ввод, целочисленное деление и остаток.

## 2. Билет на экскурсию

Цена одного билета равна `p` рублей. Группа покупает `n` билетов. Найди общую стоимость покупки.

**Входные данные:** два целых положительных числа `p` и `n`, каждое не больше 10 000.

**Выходные данные:** одно целое число — общая стоимость.

| Ввод | Вывод |
|---|---|
| `350 4` | `1400` |
| `120 1` | `120` |

**Проверяется:** переменные, ввод, присваивание, умножение и вывод.

## 3. Площадь комнаты

Комната имеет прямоугольную форму. По длине `a` и ширине `b` вычисли площадь и периметр.

**Входные данные:** два положительных вещественных числа, не превышающих 100. Дробная часть отделена точкой.

**Выходные данные:** площадь и периметр через пробел. Лишние подписи не добавляй. Для вещественного результата допустима запись с завершающим нулём, например `15` или `15.0`; проверяй числовое значение.

| Ввод | Ожидаемые значения в выводе |
|---|---|
| `3 5` | площадь `15`, периметр `16` |
| `2.5 4` | площадь `10`, периметр `13` |

**Проверяется:** тип `вещ`, арифметические выражения и скобки в формуле периметра.

## 4. Время в минутах

Дано целое число `m` — продолжительность занятия в минутах. Переведи время в полные часы и оставшиеся минуты.

**Входные данные:** одно целое число `m` (`0 ≤ m ≤ 10 000`).

**Выходные данные:** количество полных часов и остаток минут через пробел.

| Ввод | Вывод |
|---|---|
| `135` | `2 15` |
| `60` | `1 0` |
| `9` | `0 9` |

**Проверяется:** целочисленное деление и остаток.

## 5. Перестановка значений

Даны два целых числа `a` и `b`. Поменяй их значения местами, используя дополнительную целую величину, затем выведи результат.

**Входные данные:** два целых числа, каждое по модулю не больше 1 000 000.

**Выходные данные:** новые значения `a` и `b` через пробел.

| Ввод | Вывод |
|---|---|
| `3 8` | `8 3` |
| `-2 5` | `5 -2` |
| `4 4` | `4 4` |

**Проверяется:** присваивание и таблица трассировки. Перед запуском заполни таблицу значений `a`, `b` и временной величины после каждой команды.

## 6. Сколько прошло дней

Запиши программу, которая получает число дней и выводит число полных недель и остаток дней.

**Входные данные:** одно целое число `d` (`0 ≤ d ≤ 100 000`).

**Выходные данные:** количество полных недель и остаток дней.

| Ввод | Вывод |
|---|---|
| `24` | `3 3` |
| `7` | `1 0` |
| `0` | `0 0` |

**Проверяется:** самостоятельное применение `div` и `mod` к новой ситуации.

## Что приложить

- файлы программ для всех задач;

- таблицу трассировки для задачи 5;
- одну-две фразы о том, почему в задаче 3 нужны вещественные величины, а в задачах 1 и 4 достаточно целых.
